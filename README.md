# Spotify Analytics Dashboard | Power BI

## Project Overview

This Power BI dashboard analyzes Spotify streaming data to uncover trends in artist performance, track popularity, and audio features. The dashboard provides interactive visualizations that help users explore music streaming patterns and key insights.

## Tools Used

* Power BI Desktop
* Power Query
* DAX
* Data Visualization

## Dashboard Features

* Total Streams, Artists, and Tracks KPIs
* Top Artists and Top Tracks Analysis
* Audio Feature Analysis (Danceability, Energy, Valence)
* Streaming Trends by Release Year
* Artist Deep-Dive Dashboard
* Executive Insights Page

## Key Insights

* Taylor Swift is the most streamed artist in the dataset.
* Streaming activity increased significantly after 2000.
* Highly energetic and danceable tracks tend to receive more streams.
